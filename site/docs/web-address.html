Your own web address

The other way to use Sworkr away from home: a free web address of your own, with HTTPS. Tailscale is simpler and more private; this works on any phone or computer without an app.

Before you start

  • This puts your login page on the internet. Anyone can find it, and bots will try passwords. Before you do it, add a passkey on each device and turn on Away from home → passkeys only in Settings → Security & privacy, so a password alone can't get in.
  • If you only need your phone, Tailscale keeps Sworkr off the internet entirely.
  • Some internet providers don't allow it (they share one public address between many homes, called CGNAT). If step 3 never works, that's usually why: use Tailscale.

1. Get a free address with DuckDNS

  1. Go to duckdns.org and sign in. Use an account you keep private.
  2. Pick a name: you get yourname.duckdns.org. Pick something that doesn't say what it's for.
  3. Keep it pointing at your home: your home's address can change. Many routers have a Dynamic DNS setting with DuckDNS in the list (use your token from the DuckDNS page). If yours doesn't, the DuckDNS install page has a small updater for Windows, Mac and Linux.

2. Install Caddy

Caddy sits in front of Sworkr and handles HTTPS by itself: it gets and renews the certificate for your address, for free.

  1. Download Caddy for your computer and put it in a folder, for example C:\Caddy.
  2. In that folder, make a file called Caddyfile (no extension) with: 
    yourname.duckdns.org {
    reverse_proxy 127.0.0.1:8080
}
    Use 8765 instead of 8080 for the Windows app.
  3. Start it from that folder with caddy run. To have it start with the computer, see Caddy's Keep Caddy running page.

3. Open the door on your router

In your router's settings, find Port forwarding. Forward ports 80 and 443 (TCP) to the computer Sworkr runs on. Caddy needs both: 80 to get the certificate, 443 for everything else. Allow Caddy through your computer's firewall if it asks.

4. Check it

  1. On your phone, turn off Wi-Fi and open https://yourname.duckdns.org. You should see the Sworkr login with a padlock.
  2. Sign in, then add a passkey on the phone (Settings → Security & privacy → Passkeys).
  3. Turn on Away from home → passkeys only.

Good to know

  • Your computer has to be on and awake.
  • A passkey made on your DuckDNS address only works there; one made on localhost only works on the computer itself.
  • To limit passkeys to your address, add PASSKEY_ORIGINS=https://yourname.duckdns.org in the setup builder.
  • To close it again: remove the port forwarding on the router and stop Caddy.
