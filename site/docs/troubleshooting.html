If something goes wrong

Sworkr won't start

  • Windows app: if a message says Sworkr couldn't start, it gives the file with the details (sworkr.log in the Sworkr data folder). If another program is using port 8765, close it, or start Sworkr with the SWORKR_PORT setting set to another number.
  • Docker: "Docker isn't running": open Docker Desktop and wait for Engine running.
  • "Port is already allocated": something else uses port 8008. Make a setup file with another port in the setup builder.
  • Windows, "WSL" messages: Docker Desktop needs Windows' Linux part. Let it install or update it, then restart the computer.
  • Mac, "unidentified developer": right-click Start sworkr.command and choose Open.
  • The download stalls: a VPN can get in Docker's way. Pause it while Sworkr downloads the first time, then turn it back on.

I forgot my password

Docker: open a terminal in the Sworkr folder and run
docker compose exec sworkr python manage.py reset-password
Windows app: ask the other admin on your copy, or restore a backup from before. If you have a passkey set up on a device, you can sign in with that.

I lost my phone and my recovery codes

Docker: docker compose exec sworkr python manage.py turn-off-two-step <username>. Then set two-step sign-in up again and save new recovery codes on paper.

"The database can't be opened"

The key that locks it is missing: the Credential Manager entry was deleted, the sworkr_sworkr_keys volume was removed, or the data was copied to another computer without its key. Install fresh and restore your latest backup with its passphrase.

My saved email or calendar password stopped working

That happens after a restore on another computer: the saved passwords are sealed with a key that stays on the computer they were saved on. Type the password in again once.

Never do these

  • Run docker compose down -v, or delete the sworkr_sworkr_data or sworkr_sworkr_keys volumes. That is your data and the key that opens it.
  • Open Sworkr's port on your router, or point a public address at it.
