Install with Docker

Pick your options, copy one file, start it. This page writes the setup file for you.

First time with Docker

Docker runs Sworkr in a sealed box on your computer, the same way on Windows, Mac and Linux. You install it once.

  • Windows 10 or 11: install Docker Desktop. It may ask to install or update "WSL" (a part of Windows it needs): say yes, and restart if it asks. Open Docker Desktop and wait for Engine running at the bottom left. You can skip signing in to Docker.
  • Mac: download the Docker Desktop that matches your Mac: Apple chip for M1 and newer, Intel chip for older ones (Apple menu, About This Mac shows which). Drag it to Applications, open it, and wait for Engine running.
  • Linux or a home server: Docker Engine is enough; your distribution's instructions are at docs.docker.com/engine/install.
  • A NAS: Synology's Container Manager, Unraid and TrueNAS all run it (see below).

Then the easy way: download sworkr-start.zip, unzip it, and double-click Start sworkr. Or carry on below to make a setup file with your own choices.

If it doesn't start: "Docker isn't running" means Docker Desktop isn't open yet, or is still starting. "Port is already allocated" means something else uses 8008: change the port below. On a Mac, "can't be opened because it is from an unidentified developer": right-click the file and choose Open instead of double-clicking.

Sworkr's Docker setup is one file, docker-compose.yml: where your records live, which folders it can see, and who can open it. Fill in what you want below; the file updates as you type. Nothing you type here leaves your browser.

This builder needs JavaScript. Without it, use the ready-made docker-compose.yml as it is: it works without changes.

Install it

    Good to know

    • You need Docker Desktop (Windows or Mac) or Docker on Linux. Don't want Docker? The Windows app needs nothing else.
    • Already using Sworkr? Keep the name sworkr at the top of the file and your records stay where they are. Changing the data folder later starts an empty one: move your records with a backup first (how).
    • To update, run docker compose pull, then docker compose up -d, in the same folder.
    • On a Synology NAS: Container Manager → Project → Create, and paste this file. Other home servers (Unraid, TrueNAS, a Raspberry Pi 4 or 5) work the same way with Docker.
    • Never run docker compose down -v: the -v deletes your records.
    • While you're at it: other services you can run at home keep even more of your life private. AdGuard Home blocks ads and trackers for every device on your network, Nextcloud keeps your files and calendar, and ntfy sends your phone notifications.
