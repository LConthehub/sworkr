Notifications

Sworkr can send a message to your phone when it isn't open, using ntfy, a free app for iPhone and Android. Nothing is sent unless you turn it on. Set it up under Settings → Reminders → Phone notifications.

What you get

  • A heads-up before a booking or health test: 15 minutes to 4 hours before, as you choose. "A booking starts at 7:00 PM".
  • A daily summary at the hour you choose: counts such as "2 bookings today, 1 deposit to collect, 1 post to put up". It's only sent on days there's something to say.
  • A note if a scheduled post couldn't go out.

Each is sent once. The browser reminders under Reminders still work separately, but only while Sworkr is open.

Set it up

  1. Install the ntfy app on your phone.
  2. In Sworkr, tap Make one next to Topic. It picks a long random name. Turn notifications on and save.
  3. In the ntfy app, tap + and subscribe to the same topic. Then press Send a test in Sworkr.

Keep it private

  • The message passes through the ntfy server. On the public one (ntfy.sh), anyone who knows your topic can read it. That's why Sworkr insists on a long random topic there. Never share it.
  • The wording is generic by default. Ticking Name clients in the messages puts names in them, so keep it off on the public server.
  • For real privacy, run your own ntfy server, or use one a friend runs, and put its address in. An access token for your server is stored sealed and is never sent to a different server.
  • Sworkr only sends from your own computer, so it has to be on (and awake) at the time.
