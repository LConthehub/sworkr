Sworkr: your back office, on your own computer.

1. Install Docker Desktop (docker.com/products/docker-desktop) and open it once. It's the free program
   sworkr runs inside. (Haven't got it? Start sworkr opens the download page for you.)
2. Keep this folder somewhere you'll find it again, like Documents.
3. Windows: double-click "Start sworkr".
   Mac: right-click "Start sworkr.command", choose Open (only the first time), then Open again.
   Linux: run ./start.sh in this folder.
   If Docker Desktop is closed, Start sworkr opens it and waits. The first start downloads sworkr,
   which takes a few minutes.
4. Your browser opens sworkr. Make your account: the first one is yours, and it's the admin.

Later:
- "Update sworkr" gets the newest version (Linux: ./start.sh update). Your records stay, and a copy is
  saved before any upgrade.
- "Stop sworkr" stops it. Your records stay.
- Never run "docker compose down -v": the -v deletes your records.

Help: sworkr.com/docs
